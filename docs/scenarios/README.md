# Monte Carlo Scenarios

This directory contains descriptive documentation and configuration details for the Monte Carlo batches executed in Glaukopis.

## Standard Scenarios (v1.0.0)

- **Head-on Engagement**: Baseline test for all target profiles.
- **Stealth Boundary Test**: Specific verification for F-35 detection ranges.

*Detailed analysis for each scenario is generated in the `results/` folder after a batch run.*
